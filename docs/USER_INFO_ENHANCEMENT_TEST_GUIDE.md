  - **所属班级**：显示 `1` 个徽章

    - 进度条显示完成率

✓ 管理操作按钮：

## 边界条件测试

### 1. 空数据处理

- [ ] 用户没有昵称：不显示昵称行
- [ ] 用户没有真实姓名：不显示真实姓名行
- [ ] 学生不属于任何班级：不显示班级区域
- [ ] 学生没有作业：不显示作业统计区域

### 2. 特殊字符

**测试数据：**
```sql
UPDATE active_users 
SET nickname = '测试<script>alert(1)</script>', 
    real_name = 'O''Brien' 
WHERE username = '250201';
```

**预期结果：**
- [ ] HTML特殊字符被正确转义
- [ ] SQL注入被防止
- [ ] 单引号正确显示

### 3. 长文本

**测试数据：**
```sql
UPDATE active_users 
SET nickname = '这是一个非常非常非常非常非常非常长的昵称用来测试布局' 
WHERE username = '250201';
```

**预期结果：**
- [ ] 长文本不会破坏布局
- [ ] 文本自动换行或截断
